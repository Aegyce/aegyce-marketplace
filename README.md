# Aegyce Marketplace

The marketplace for reusable components from Aegyce agents, organized by agent. Components may include skills, MCP integrations, tools, and other capabilities supported by the receiving AI tool.<br>
<sub>Aegyce 各 Agent 可复用组件的插件市场，按 Agent 组织。组件可包括 Skill、MCP 集成、工具及使用方 AI 工具支持的其他能力。</sub>

[Aesy](https://github.com/Aegyce/agent-aesy) is Aegyce's general-purpose agent. The `aesy` plugin currently distributes its `computer-technical-language` skill.<br>
<sub>[Aesy](https://github.com/Aegyce/agent-aesy) 是 Aegyce 的通用 Agent，`aesy` 插件当前分发其中的 `computer-technical-language` Skill。</sub>

AI tools that support this marketplace format can install its plugins. Individual components are also available from the linked agent repositories for use through the tool's supported interfaces.<br>
<sub>支持该市场格式的 AI 工具可安装其中的插件，也可从对应 Agent 仓库获取单项组件，通过所用工具支持的接口接入。</sub>
