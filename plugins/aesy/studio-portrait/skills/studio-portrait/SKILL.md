# 高质感影棚肖像

将原照中的人物特征、目标服装和统一摄影棚光线组合为自然、清晰、有空间感的商务肖像。优先服从用户本轮要求，使用下述默认风格填补未指定的细节。

## 1. 确认输入职责

先查看图片，给每张图片指定唯一的主要职责，再编写提示词。

| 输入 | 用途 | 不继承的内容 |
| --- | --- | --- |
| A：用户原始照片，必需 | 本人五官、表情、发型、真实肤质、身体比例 | 需要替换的服装、背景；用户已要求调整的光照 |
| B：当前认可的样式图，可选 | 已确定的西服、背景、构图与画幅 | 其中已经退化、模糊或漂移的面部细节 |
| C：摄影风格参考，可选 | 背景色调、摄影质感、布光、画幅 | 参考人物的长相、发型和姿势，除非用户另有明确要求 |

- 用户未提供样式图时，使用 `assets/style-reference.png` 作为 B。这是本次已认可成片，仅提供风格；给其他人修图时不得借用该图中的人物特征。
- 同一图承担两种参考用途时，合并职责并明确写出。不要为了满足模板虚构第三张图片。
- 新任务没有原照，或原照的脸部严重遮挡、被裁掉、无法辨识时，索取原照。清晰的正面照片足够时直接执行；额外照片只用于解决具体识别问题。
- 修正当前任务时保留原照作为持续依据。若发现多轮生成后细节下降，改用 A 作为主图，以 B 提供样式，不继续把受损面部当作唯一依据。

## 2. 提取参数与固定约束

默认使用已认可风格；用户的新要求覆盖默认值。

| 参数 | 默认值 |
| --- | --- |
| 人物 | 保留用户原照中的五官几何、眼形、表情、发型和自然比例 |
| 服装 | 高品质炭灰色精纺羊毛商务西服、白衬衫、深蓝色真丝质感领带 |
| 西服品质 | 合体肩线、自然垂坠、立体翻领、细腻克制的织纹与反光 |
| 背景 | 低饱和深蓝灰，宽缓渐变，边缘更暗，纹理弱且略虚 |
| 布光 | 左前方约 30°、略高于眼位的大面积柔光；近镜头位置较弱补光 |
| 面部 | 眉眼、睫毛、鼻翼和唇缘清晰；皮肤细腻自然、无粗糙假纹理 |
| 眼神 | 小而自然的眼神光，清楚的虹膜与眼白层次，保持原眼形和视线 |
| 画幅 | 优先用户指定尺寸或参考图实测比例；未指定时采用 20:23 竖版 |

区分“人物不能改变”和“可以调整的光照”。保持身份不等于锁死原图的曝光、阴影和白平衡。用户要求统一布光时，允许脸、颈部和衣物一同调整光线。

先读取参考图的真实尺寸，别凭外观认定比例。若 Pillow 可用，执行只读检查：

```bash
python scripts/inspect_image.py /absolute/path/reference.png
python scripts/inspect_image.py /absolute/path/result.png --target-ratio 20:23
```

该脚本只读取图片元数据，不修改或重采样图片。工具不具备 Pillow 时，使用可用的只读图像信息工具。

## 3. 使用图像编辑能力

1. 使用当前环境提供的图像生成/编辑工具。若有 imagegen 技能，遵循其调用约定。
2. 查看所有本地输入图片后再编辑。使用真实、存在的路径；不要硬编码本次会话的临时路径。
3. 对支持 `referenced_image_paths` 的工具，按 A、B、C 的角色传入实际需要的图片，并在提示词逐项解释。若只能引用会话图片，使用该工具支持的引用机制。
4. 读取 `references/prompt-template.md`，用已确认的图片角色、尺寸目标和用户要求替换占位符。删除不存在的参考图和不适用的段落。
5. 仅传工具实际支持的字段。不要凭空增加 `size`、`seed`、`mask`、`quality` 或锁定人脸等参数。仅在提示词中写入的分辨率和摄影参数属于目标描述。
6. 没有可用图像编辑能力时说明能力缺口，提供可执行的提示词；不要把 HTML、SVG、普通滤镜或未执行的命令当成完成的照片。不要未经用户要求切换为付费 API/CLI。

执行时把脸、头发、脖子、衬衫和西服视为一个受光主体。让鼻影、颊侧明暗、下颌阴影、领口接触阴影和翻领高光具有一致方向。让背景的柔和程度和明暗层次体现距离，而不靠头部亮光圈制造分离。

## 4. 核验并定向修正

用原照、用户参考和生成结果进行目视对照。依次检查：

1. **人物一致性**：眼形、眉毛、鼻唇轮廓、耳朵、下颌、发型、表情和头身比例是否出现可见漂移。
2. **清晰度与肤质**：眼睛、睫毛、眉毛和唇缘是否清楚；皮肤是否出现波浪纹、颗粒堆积、磨皮涂抹或锐化白边。
3. **统一布光**：脸、颈部与衣服的主光方向和阴影是否一致；脸是否过亮、偏橙、像贴上去；眼神光是否与主灯位置相符。
4. **服装和空间感**：西服是否合体、有真实织物和翻领层次；背景是否低饱和、深邃、柔和而不抢眼。
5. **画幅**：读取结果的实际宽高，核对参考比例；人物不得因匹配比例而拉伸。

遇到具体问题时读取 `references/corrections.md`。只修正当前问题，并重申已认可部分；避免每次把全部风格重新设计。

若肤质、五官或清晰度出现累计退化，回到原照重新约束人物，保留当前认可的样式。不要用不断叠加磨皮、锐化和假细节补救受损面部。

没有新的可见问题、用户已认可结果时停止迭代。复用技能不需要先重演本次失败的版本。

## 5. 交付与准确说明

- 按当前图像工具规定展示结果。对于已经自动显示和保存的生成图，不重复上传或建立额外副本，除非用户另有交付要求。
- 用简短文字说明本轮实际调整，不承诺逐像素不变或每次生成完全相同。
- 把“提示词要求”与“已核验事实”分开。灯位、f/8、低 ISO、背景距离是摄影效果描述，不是照片的实拍 EXIF 或实际可控灯具参数。
- 未读取实际尺寸前，不宣称成片达到某个分辨率。即使肉眼比例相同，也不能把近似比例说成严格一致。
- 用户要求严格尺寸时，优先使用图像工具真实支持的尺寸控制；若仍不满足，报告差异，并依当前工具规则处理后续尺寸调整。不得悄悄拉伸人物，也不得虚报达标。
- 不把“要求保留原图像素”说成已执行抠图、蒙版或像素回贴；没有调用对应功能就不能声称做过。
