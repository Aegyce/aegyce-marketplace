# 定向修正与验收

先依据用户实际指出的问题和可见图像选择一项。不要为了提高“高级感”同时修改身份、肤质、服装、构图和背景。

| 症状 | 优先查看 | 定向修正 | 避免 |
| --- | --- | --- | --- |
| 脸像贴上去 | 脸颈色温、脸部亮度、下颌与领口阴影 | 将脸、颈部和西服统一布光 | 一边锁定原光照，一边要求改光 |
| 五官不像本人 | 与最初原照逐项对照 | 用原照作为主要人物输入，样式图仅负责服装与背景 | 继续从已经漂移的脸生成 |
| 面部模糊 | 睫毛、眉毛、鼻翼、唇缘是否可辨 | 回到原照约束真实结构与细节 | 对整张脸强锐化、用毛孔噪点伪装细节 |
| 皮肤粗糙 | 假毛孔、波浪纹、重复颗粒、阴影过硬 | 减少异常纹理与局部微反差，保留结构边界 | 全局模糊、过亮磨皮 |
| 皮肤像塑料 | 额头、脸颊是否缺乏自然层次 | 恢复原照真实细腻纹理和柔和明暗 | 反向增加大量假毛孔 |
| 眼神无神 | 眼神光方向、虹膜和眼周暗部 | 小幅调整自然反光与局部层次 | 大眼、改变瞳孔、漂白眼白、美瞳感 |
| 西服廉价 | 肩线、领口、翻领体积、垂坠 | 用剪裁、材质和克制反光表现品质 | 用夸张织纹、塑料高光冒充质感 |
| 背景太亮或太蓝 | 饱和度、边缘亮度、头部光圈 | 低饱和深蓝灰，渐变更缓，保留层次 | 一律压成纯黑，或饱和宝蓝 |
| 空间感不足 | 背景是否与脸同样清晰、纹理是否抢眼 | 弱化远处背景细节，统一主光并拉开层次 | 硬抠图边缘、发光描边 |
| 比例不符 | 实际宽高与参考比值 | 先核验尺寸，用支持的画幅控制调整 | 凭肉眼报严格一致、拉伸人物 |
| 局部修改造成全面变化 | 原照、最近认可版、本轮结果 | 保留最近认可的样式，以原照重新约束人物 | 无限累积修补，或沿用失败图全部细节 |

## 统一光线检查顺序

1. 先确定主光从哪边照射，再检查额头、鼻影、颊侧和下颌。
2. 沿下颌向下查看颈部，再查看白衬衫领口的接触阴影。
3. 查看同侧肩膀、翻领和袖山是否与脸部受光一致。
4. 查看双眼反光方向与主光是否相符；不要要求两个反光形状逐像素相同。
5. 查看背景是否退到人物后面，发缘是否出现假白边或光晕。

以上是目视审查顺序，不是物理光照测量或三维重建。

## 比例与清晰度分别核验

- 分辨率高不等于面部细节真实；不能只看文件大小或像素数判断清晰度。
- 肤质柔和不等于失焦；用眉眼、睫毛和唇缘判断结构清晰度。
- 20:23 是画幅目标，不代表必须把人物缩放成参考人物的身材或姿态。
- 例如 1169×1345 的比值非常接近 20:23，但不是严格相等；报告实测结果。
- 工具若只接受自然语言描述尺寸，应预期需要实际读取结果，而不是把提示词里的尺寸复制到交付说明。

## 停止条件

用户已经接受效果，或本轮问题得到合理修正且没有新的明显退化时，停止生成。不要为了重复验证而继续重绘面部。仍存在具体问题时，只针对该问题修正；若原照本身缺少需要的可见信息，再索取更清楚的原照。
