# Aegyce Marketplace

The marketplace index for Aegyce agent capability packages.<br>
<sub>Aegyce 各 Agent 能力包的插件市场索引。</sub>

[Aesy](https://github.com/Aegyce/agent-aesy) is Aegyce's general-purpose agent capability package. It currently includes the `computer-technical-language` skill.<br>
<sub>[Aesy](https://github.com/Aegyce/agent-aesy) 是 Aegyce 通用 Agent 的能力包，当前包含 `computer-technical-language` Skill。</sub>

Add this marketplace and install Aesy in Codex CLI:<br>
<sub>在 Codex CLI 中添加市场并安装 Aesy：</sub>

```bash
codex plugin marketplace add Aegyce/aegyce-marketplace
codex plugin add aesy@aegyce-marketplace
```

In supported ChatGPT desktop clients, add `Aegyce/aegyce-marketplace` as a marketplace source, then select and install Aesy.<br>
<sub>在支持该入口的 ChatGPT 桌面客户端中，将 `Aegyce/aegyce-marketplace` 添加为插件市场来源，再选择并安装 Aesy。</sub>
