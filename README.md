# Aegyce Marketplace

Aegyce 各 Agent 可复用组件的插件市场，按 Agent 组织。组件可包括 Skill、MCP 集成、工具及使用方 AI 工具支持的其他能力。<br>
<sub>The marketplace for reusable components from Aegyce agents, organized by agent. Components may include skills, MCP integrations, tools, and other capabilities supported by the receiving AI tool.</sub>

## 当前插件<br><sub>Available plugins</sub>

- [Aesy](https://github.com/Aegyce/agent-aesy)：Aegyce 通用 Agent 的对外插件，当前分发 `computer-technical-language` Skill。<br>
  <sub>The plugin for Aegyce's general-purpose agent, currently distributing the `computer-technical-language` skill.</sub>

## 使用方式<br><sub>Usage</sub>

支持该市场格式的 AI 工具可安装其中的插件，也可从对应 Agent 仓库获取单项组件，通过所用工具支持的接口接入。<br>
<sub>AI tools that support this marketplace format can install its plugins. Individual components are also available from the linked agent repositories for use through the tool's supported interfaces.</sub>
