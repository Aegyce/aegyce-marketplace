# Aegyce Marketplace

Reusable capabilities for AI tools, organized by Aegyce agent. This repository indexes each agent's capability package.<br>
<sub>面向 AI 工具的可复用能力市场，按 Aegyce Agent 组织。本仓库索引各 Agent 的能力包。</sub>

[Aesy](https://github.com/Aegyce/agent-aesy) is Aegyce's general-purpose agent capability package. It currently includes the `computer-technical-language` skill.<br>
<sub>[Aesy](https://github.com/Aegyce/agent-aesy) 是 Aegyce 通用 Agent 的能力包，当前包含 `computer-technical-language` Skill。</sub>

AI tools that support this marketplace format can install its agent packages. Individual capabilities are also available from the linked agent repositories for use through the tool's supported interfaces.<br>
<sub>支持该市场格式的 AI 工具可安装其中的 Agent 能力包，也可从对应仓库获取单项能力，通过所用工具支持的接口接入。</sub>
