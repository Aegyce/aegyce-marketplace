## 关键迭代经过

### 1. 从更换背景和服装起步

用户最初要求背景改深色、服装改正装，其他内容保持不变。
原照为白色背景，人物穿浅灰外套和白色圆领内搭。
初期编辑尝试深色背景与西服，但用户指出光线不对、面部处理不贴合。
由此可见，仅替换背景和服装，并不足以得到自然的整体摄影效果。

### 2. 根据用户参考明确背景与服装

用户进一步明确背景应为渐变深蓝，并提供了一张影棚人像作参考。
参考价值在于低饱和蓝灰背景、柔和过渡、摄影空间感与正装质感。
随后明确“正装”应是面料和剪裁都显得优质的西服，而非只改变衣服类别。
迭代逐步收敛到炭灰西服、白衬衫、深蓝领带及深蓝灰背景的组合。

### 3. 修正光线、空间、肤质与画幅

用户继续指出面部突兀、背景不够深邃、整体空间感不足。
后续编辑加强了深色背景的层次，并尝试调整面部与服装的光照关系。
用户又指出皮肤太粗糙，并要求画幅与参考图一致，因而加入自然肤质和 20:23 画幅约束。
“眼睛要灵动”的反馈被转化为自然眼神光、清晰眼部细节与有神的注视。
这些修订形成了可保留的风格，但用户仍指出面部模糊、灯光不像摄影棚。

### 4. 最终重新以原照约束面部

最终调用重新将最早原照列为首要编辑输入，同时保留近期草稿和用户影棚参考图。
提示词要求从原照保留人物特征和清晰细节，不沿用草稿中已经模糊的面部或异常材质纹理。
近期草稿承担服装、背景与构图参考；影棚参考承担摄影风格参考。
同时明确全身可见部分共用一套合理的影棚光照，并分别描述肤质、眼睛、服装和背景。
用户认可了这一版本；这证明该次结果满足其审美要求，不代表每个提示词条件都可自动精确实现。

## 最终调用如何组织参考图

最终实际使用了三张图片，通过 `referenced_image_paths` 一并提供给图像生成工具。
背景为不透明，调用设置为 `transparent_background: false`。

| 输入顺序 | 图片角色 | 明确允许参考的内容 | 应避免继承的内容 |
| --- | --- | --- | --- |
| 第一张：最早原照 | 身份与面部依据、主要编辑对象 | 五官结构、头型、发型、表情、年龄感、身体比例 | 不必保留已获授权调整的原背景、服装与光照 |
| 第二张：近期生成草稿 | 已收敛的风格草稿 | 西服搭配、背景方向、画幅与构图 | 模糊面部、变形特征、粗糙皮肤或异常织物纹理 |
| 第三张：用户影棚参考 | 摄影风格依据 | 背景层次、摄影空间感、自然布光 | 参考人物的脸、身份、发型及未经用户要求的姿势 |

参考图的作用由提示词明确约束，不是工具提供的硬性图层隔离功能。
后续任务可以只用当前原照和附带风格图，不要求人为制造一张中间草稿。

## 定稿提示词中的有效约束

### 人物与清晰度

- 指明原照是唯一的人物身份依据，保留原有眼形、眉形、鼻唇、耳朵、下颌和发际线。
- 将清晰度落实到睫毛、眉毛、虹膜、鼻翼和唇缘等结构，不用额外皮肤噪点冒充细节。
- 保留自然、细腻的肤质，避免蜡感、大片磨皮、浮雕状毛孔、旋涡纹理与锐化光晕。
- 让眼神自然有神，保持原有眼睛大小、眼睑形态和视线，避免夸张眼白或玻璃珠效果。

### 灯光与空间

- 描述一个连贯的影棚照明方案，使面部、颈部、衣领、肩部与西服受光方向一致。
- 最终提示词使用相机左侧约 30°、略高于眼睛的大型双层柔光八角灯作为主光描述。
- 辅光描述为靠近相机、比主光低约一档；阴影保持柔和，避免硬阴影与整体灰雾。
- 以克制的鼻影、颊部明暗、下颌与衣领阴影衔接人物，避免脸像贴在衣服上。
- 背景采用低饱和深午夜蓝灰、宽而柔和的渐变和更暗边缘，不形成头后强烈亮圈。
- 通过背景的柔和程度和明暗层次表达空间，不把面部一起模糊来制造景深。

### 服装与画幅

- 服装描述为优质炭灰精纺羊毛西服、白衬衫与深蓝丝质领带。
- 让合体剪裁、肩线、驳头、垂坠和克制的材质反光体现品质，避免夸张重复织纹。
- 要求 20:23 竖幅，并以 1920 × 2208 或更高同比分辨率作为生成目标。
- 最终实际输出仍为 1169 × 1345；交付尺寸以实际检查为准。

## 从失败迭代提炼的规则

| 遇到的问题 | 下一次应采用的规则 |
| --- | --- |
| 换背景后脸部显得突兀 | 把脸、颈部和服装视为同一受光主体；在获授权后统一光照 |
| 多轮编辑后不像原人 | 返回原照校准身份，仅从成熟草稿借用已经认可的风格 |
| 提高清晰度后皮肤变粗糙 | 指定真实结构边缘与自然肤质，禁止用噪点和锐化代替清晰 |
| 磨皮后面部发糊 | 减少纹理异常时保留眉眼鼻唇的局部结构，避免全脸平滑 |
| 眼睛有神却改变了长相 | 优先调整合理眼神光和局部明暗，保留眼形与视线 |
| 西服显得廉价或像塑料 | 强调剪裁、垂坠、肩线及轻微织纹，抑制油亮与重复纹理 |
| 背景饱和、平板或有光圈 | 指定低饱和深蓝灰、宽渐变与较暗边缘，避免发光轮廓 |
| 构图正确但画幅不符 | 先读取参考尺寸，再核验输出尺寸；不要靠拉伸人物修比例 |
| 改好一个问题又破坏其他部分 | 明确本轮要改的项目和需保留的已认可项目；质量退化时重新从原照开始 |

## 可复用的执行顺序

1. 获取当前人物原照，并分清每张图片是身份依据、风格参考还是近期草稿。
2. 提炼当前用户已授权的变化；若要求“其他不变”，不要自行改变姿势、体型或表情。
3. 读取目标参考图尺寸，将画幅要求与人物比例要求分别写清楚。
4. 一次整理身份、肤质、布光、西服、背景和构图约束，优先生成完整且一致的版本。
5. 将结果与原照和风格目标分别比较，定位具体问题，使用少量有针对性的修订。
6. 若出现身份漂移或连续模糊，重新从原照编辑，用认可草稿辅助传递风格。
7. 核验实际尺寸与视觉结果；只有用户认可或关键要求已得到验证，才作为定稿交付。

## 技术边界与交付表述

本次实际方法是基于多张参考图与文字要求的生成式图像编辑，并进行了图片查看和尺寸核验。
没有实际执行 Photoshop 抠图、手绘蒙版、频率分离、逐像素贴回、三维人脸重建或独立超分辨率流程。
提示词中的“局部调整”“保持不变”属于编辑约束，不能据此宣称已进行硬性像素锁定。
`f/8`、低 ISO、中画幅质感、灯位、辅光档差和背景距离都是视觉效果描述，不是实拍 EXIF 或真实器材记录。
提示词中的 1920 × 2208 是期望尺寸，不是该次输出的实际尺寸，也不是工具对分辨率的保证。
生成式编辑可能重绘细节；相似度可以审查和改进，但不能承诺身份特征绝对不变或原始像素完整保留。
生成出的睫毛、织纹或皮肤细节，也不能被描述为已经准确恢复了原照中未记录的信息。
本 Skill 固化的是输入分工、约束和验收方法，不能保证不同原照或多次调用得到完全相同的结果。
